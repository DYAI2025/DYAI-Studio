# Product Canvas — Template

## Target user
Who has the problem?

## Trigger / context
When does the problem become important?

## Current problem
What observable friction, cost, risk or missed outcome exists?

## Current alternatives
How is it handled today?

## Desired state change
What should become measurably different?

## Value hypothesis
Why would that change matter enough to act/pay?

## Smallest useful intervention
What is the minimum end-to-end test?

## Evidence plan
What would support or falsify the value hypothesis?

## Constraints
Trust, legal/privacy, technical, adoption, budget, time.

## Asset potential
What might become reusable if this works?

## Status
USER_STATED / DERIVED / ASSUMPTION / VERIFIED / BLOCKED
