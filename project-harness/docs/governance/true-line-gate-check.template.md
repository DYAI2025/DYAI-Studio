# True-Line Gate Check

## Claim
What exactly is being claimed?

## Required evidence class
What minimum evidence can support this claim?

## Available evidence
List concrete URLs, commits, Jira issues, test results, runtime observations or user confirmations.

## Contradictions
Any evidence that conflicts with the claim?

## Verdict
- SUPPORTED
- PARTIALLY_SUPPORTED
- UNRESOLVED
- CONTRADICTED
- BLOCKED

## Residual risk
What remains unproven?

## Next verification
Smallest action that can materially change the verdict.
